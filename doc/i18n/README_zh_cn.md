一个为 Minecraft 引入伪装型苦力怕变体的模组。

[English README](../../README.md)

## 新增生物

### 苦蜜怕

头顶戴着蜂巢的蜂蜜主题苦力怕变体。

**生成与转化**
- 苦力怕在蜂巢周围 `12*8*12` 格范围内自然生成时，生成苦蜜怕而非苦力怕。
- 手持未储存蜜蜂的蜂巢右键普通苦力怕，会把蜂巢扣到它头上并将其转化为苦蜜怕。
- 使用 `/summon creeper_rearranged:honeeper ~ ~ ~ {HoneyLevel:%d}` 以生成具有特定(`%d=0/1/2/3`)蜂蜜等级的苦蜜怕。

**行为**
- 与普通苦力怕行为完全一致。
- 苦蜜怕会吸引携带花粉的蜜蜂；携带花粉的蜜蜂靠近头顶蜂巢后会失去花粉，并使蜂巢蜂蜜等级 +1。蜂蜜等级达到 3 时苦蜜怕进入满蜜状态。
- 满蜜爆炸：爆炸伤害减半，命中生物获得缓慢效果；每个被炸毁的方块各有 50% 概率被替换为蜂蜜块。

**收割**
- 对满蜜苦蜜怕使用剪刀会掉落 3 个蜜脾；使用玻璃瓶会得到蜂蜜瓶（空瓶被灌满）。两种收割都会清空蜂巢，需要蜜蜂重新填充。
- 收割不会激怒蜜蜂。

**掉落**
- 必定掉落：1 个（空的）蜂巢与 0-2 个火药。
- 满蜜状态下：各有 50% 概率额外掉落 1 个蜂蜜块与 1 个蜜脾。

**兼容性**
- 安装 Jade 后，注视苦蜜怕会显示其蜂蜜等级（“蜂蜜等级：x/3”，满蜜时额外提示“满蜜”）。
